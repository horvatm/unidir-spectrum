# Spectrum of classically unidirectional billiards

This repository will host `unidir_spectrum`, a Python package with a C++ backend for computing the energy spectra and eigenstates of classically unidirectional billiards using the finite element method (FEM) and the Vergini–Saraceno (VS) scaling method.

The package and the spectral data accompanying the paper are being prepared for public release. The software will be released under the GNU General Public License v3 (GPL-3.0).
